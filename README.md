# Tablekeep Lite downloads

[Download the latest release](https://github.com/chrislandouw-lab/tablekeep-lite-downloads/releases/latest)

Tablekeep Lite is a Windows desktop host for a DM computer, private player character sheets, and a shared display. Players join from their phone browsers on the same Wi-Fi.

Download the Windows installer from the release assets and run it on the computer that hosts your game. Open Connections in Lite to get the player link or QR code. Phones do not need the Windows installer.

Version 0.5.6 adds in-app updates. Install it once, then use Table settings -> Check for updates for future releases. Updates keep campaign saves in the same application data directory.

Each release includes a SHA256.txt checksum file. The app verifies installer downloads before offering to run them.

This repository distributes installers and release notes. Application source and saved campaign data stay outside this repository.
